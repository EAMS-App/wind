# EAMS-App 風データ（wind.json）自動生成

このリポジトリ（`EAMS-App/wind`・Public）は、EAMS-App の地図に表示する**風の矢羽根データ
`wind.json`** を、NOAA の GFS 予報から**1日4回・自動で**作り直すためのものです。
発注者（非技術者）向けに、最短の置き方と初回の動かし方だけをまとめます。

## 中身（2ファイルだけ）

| ファイル | 置き場所 | 役割 |
|---|---|---|
| `gfs_wind.py` | リポジトリの**直下** | GFS から風を取って `wind.json` を作るプログラム |
| `gfs-wind.yml` | **`.github/workflows/`** の中 | 上のプログラムを自動で回す設定（GitHub Actions） |

> 生成物 `wind.json` は自動で作られてこのリポジトリ直下にコミットされます。手で作る必要はありません。

## ファイルの置き方

1. このリポジトリに `gfs_wind.py` を**直下**（トップ階層）に置く。
2. `.github` フォルダ → その中に `workflows` フォルダを作り、`gfs-wind.yml` を入れる。
   最終的にパスは `\.github\workflows\gfs-wind.yml` になります。
3. どちらも `main` ブランチに入れてください（コミット）。

## 初回だけ：手動で1回動かす

1. ブラウザで **Actions** 画面を開く → `https://github.com/EAMS-App/wind/actions`
2. 左の一覧から **「GFS wind.json」** をクリック。
3. 右側の **「Run workflow」** ボタン → もう一度 **「Run workflow」** を押す。
4. 数分待つと緑のチェック（成功）になります。
   - 成功すると、リポジトリ直下に `wind.json` が自動でコミットされます。

## 成功の確認

ブラウザで次の URL を開いて、風データ（数字がぎっしりの JSON）が表示されれば成功です（200 OK）。

```
https://cdn.jsdelivr.net/gh/EAMS-App/wind@main/wind.json
```

- 表示されない場合は数分おいて再読み込みしてください（配信キャッシュの反映待ち）。
- ワークフローの最後で配信キャッシュ（jsDelivr）の更新指示（purge）を自動で送っているため、
  通常はすぐ最新になります。

## 以降は全自動

置いたあとは、毎日 **UTC 04:25 / 10:25 / 16:25 / 22:25**（日本時間で 13:25 / 19:25 / 翌 1:25 / 7:25）に
自動で最新の風に更新されます。手動操作は不要です。

## うまくいかないときの目安

- Actions が**赤いバツ**で失敗する：多くは GFS の公開待ち（プログラム側で最大24時間さかのぼって
  探し、それでも取れなければ、壊れたデータを置かないよう**わざと失敗**します）。時間をおいて
  「Run workflow」をもう一度押せば直ることがほとんどです。
- 前回の `wind.json` は失敗時もそのまま残る設計なので、地図の風表示が消えることはありません。
